# LUMINA — Official Manga Website

This is the complete Lumina website package.

## Files
- `index.html` — main website page
- `style.css` — website styling and responsive layout
- `favicon.png` — Lumina browser tab icon
- `README.md` — this guide

## Upload to GitHub Pages
1. Open your GitHub repository.
2. Upload all four files into the same folder as your website.
3. Make sure the main page is named exactly `index.html`.
4. Keep `style.css` and `favicon.png` in the same folder as `index.html`.
5. Commit the changes.
6. Refresh your GitHub Pages website.

The Gallery text is set to: “Manga panels and sketches here.”
The favicon is already linked in `index.html`.
